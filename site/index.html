WHY THIS EXISTS

The only commercial option is a $250 one‑way clock box.

Ableton Link is the modern standard for tempo and phase sync across apps, devices and laptops. In Eurorack, that standard has been served by a single 2HP module with two outputs, no display, and traffic in one direction only. NEON LINK starts from the other end: a full Link citizen that can also drive the session from your rack’s clock, carry BLE MIDI into CV, and explain itself on its own screen.

WHAT IT DOES

Two surfaces of the same object.

The panel is the live instrument face; the web editor is the expanded control surface. Same words, same icons, same numerals — generated from one set of design tokens so they cannot drift apart.

Ableton Link, both ways

Joins a session over WiFi, follows tempo, phase and start/stop — and can just as happily take your rack’s Clock In and set the session tempo for everyone else.

Tempo CV + flexible clock

One jack tracks tempo as CV over a configurable BPM range; the other is a clock, gate, or three flavours of reset — with PPQN, multiply/divide, shuffle, pulse shape and free-run per output.

Rhythm Explorer

Euclidean, probability, or free-assignment 64-step patterns on every clock, each with chance and jitter, spread over the PPQN grid or across the whole loop.

BLE MIDI bridge

Advertises as a Bluetooth MIDI device: notes drive gates, pitch can drive 1 V/oct CV, CCs map to live parameters, and incoming clock can be ignored, merged, or adopted. One toggle kills the radio entirely.

A UI you can gig with

Hero tempo in purpose-built seven-segment numerals, a phase bar, and full-screen beat numbers you can read across a dark stage. Encoder menus reach every parameter without a phone.

A web editor in 60 kB

Served by the module itself in a single request — no internet, no CDN, no app store. Setup wizard, four presets, WiFi manager, OTA firmware updates with rollback.

One knob, three moves

ROTATEMove focus, or change the focused value.
SHORT PRESSEnter, confirm, toggle.
LONG PRESSCancel an edit in progress; otherwise go back one level. It fires the moment the hold threshold passes, so the panel reacts under your finger.

While browsing, focus is a caret. While editing, the whole row inverts — the knob’s mode is never ambiguous. And tempo is deliberately not editable from the live screen: an encoder that changes tempo on an accidental nudge is a hazard on stage.

The jack field

NEON LINK v1 runs on the shorepine AMYboard — a 10HP ESP32‑S3 module with a 5×2 jack block. Tap a jack to see what the firmware puts on it.

First boot, three minutes

  1. Power it. Eurorack +12 V or USB‑C. With no stored credentials the module raises its own open access point, NEON-LINK-XXXX, after about ten seconds.
  2. Join the AP and open http://192.168.4.1/. The same address is on the panel — the strongest moment of cohesion in the whole product: the screen is showing you the URL you just typed.
  3. Enter your WiFi and save. 2.4 GHz only — the radio cannot see 5 GHz networks. The setup AP stays up while it associates, so you are never cut off mid-setup. When the panel flips from AP to STA with an address, it has joined — from then on it answers at http://neon-link.local/.

WiFi failures come back as sentences, not error codes: “Handshake timed out — usually a wrong password.”

INTERACTIVE MANUAL · PART 2

The web editor.

The page the module serves is Preact + TypeScript, inlined into a single gzipped response under 60 kB — a design budget, not a flash limit, so setup stays fast over a 2.4 GHz link you’re standing on. Five pages plus a first-boot wizard; pick one.

TRY IT

The Rhythm Explorer, in your browser.

Every clock output can run a pattern instead of a straight grid. This is the same math the firmware uses — a Euclidean distribution with rotation, and per-step chance on top. It runs off the simulator’s tempo, so if you tapped 140 up top, this is playing at 140.

On hardware this runs to 64 steps per output, as Euclidean, probability, or free-assignment masks you paint by hand in the editor — and a pattern can span the whole loop instead of the PPQN grid.

HARDWARE — V1 ON AMYBOARD

Form factor10HP Eurorack, skiff-friendly
BrainESP32‑S3 — core 0 runs networking, Link, BLE and the web server; core 1 runs the pulse engine alone, scheduled by hardware timer at 1 µs
CV out2× via GP8413 DAC — Tempo CV (0–5 V over a set BPM range, or 1 V/oct pitch) and clock/gate/reset
CV in2× via ADS1015 — Clock In and Reset In, rising edge ≥ 1 V, sampled at ~1 kHz
MIDITRS Type A out at 31,250 baud; BLE MIDI in over the air
Display128×128 OLED over I²C — SSD1327, SH1107 or SSD1306 probed at boot
NetworkWiFi 2.4 GHz, four stored networks walked in order, plus its own setup AP
FirmwareTwo OTA slots — update from the editor, roll back if it goes wrong
CostComponent BOM under $75 — the AMYboard base is about $30

BUILD & FLASH

git clone https://github.com/johnnyclem/neon-link
cd neon-link
git submodule update --init --recursive
. ~/esp/esp-idf-v5.3.2/export.sh
idf.py set-target esp32s3
idf.py -DSDKCONFIG_DEFAULTS=\
  "sdkconfig.defaults;sdkconfig.defaults.amyboard" build
./scripts/flash_amyboard.sh

First flash needs erase-flash (the partition table carries two OTA slots); after that, the editor’s INSTALL UPDATE button is enough. Flashing replaces the AMYboard’s stock MicroPython — it can be restored from amyboard.com.

TIMING, HONESTLY

Pulse scheduling is microsecond-accurate on its own core. Jack edges cross an I²C DAC, so gate jitter is on the order of a millisecond — right for modular clocks, not for audio-rate. External clock following is good for tempo tracking, not sample-accurate phase lock. The status page shows you the engine’s worst and average lateness in µs, live.
