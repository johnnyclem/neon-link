; NEON LINK icon masters — pure 1-bit, 8x8, hand-authored.
;
; DESIGN_SYSTEM.md §7: design the icon once in 1-bit, then derive the colour
; version for the web. We author at 8x8 because that is the size the device
; header actually renders, and the web draws the SAME master as a crisp SVG
; pixel grid at 2x/3x. The web literally shows the device's pixels — which is
; the most direct expression of "two surfaces of the same object" we can get.
;
; Format
; ------
;   @name [clock]   starts a glyph. Everything after it is pixel rows, in
;                   blocks of exactly 8. One block = a static icon; several
;                   blocks = the frames of a loop, in order.
;   '#' lit, '.' off. Lines starting with ';' are comments. Blank lines are
;   ignored, so frames can be spaced apart for readability.
;
; `clock` is what advances the frame, and it is per icon because the two
; kinds of motion mean different things:
;
;   beat   one frame per musical beat, from the same phase the panel's bar
;          and the web's strip already share. These loops speed up when the
;          tempo does, so the panel visibly runs at the tempo rather than
;          just reporting it. This is the motion that only makes sense on a
;          clock module, and it is the reason to have animation here at all.
;   tick   a fixed 5 Hz counter, for things with no musical time — a radio
;          beaconing, a stack advertising.
;   (none) static. The default, and still the right answer for most icons.
;
; Motion is meaning, not decoration (§8): an icon moves only while the thing
; it stands for is actually happening. Settled states hold still — `stop`
; must not move, `check` is momentary, and `warning` stays put because a
; steady error is easier to read than a flashing one.
;
; Style rules: geometric, closed shapes where possible, consistent weight,
; no antialiasing, no filled blobs unless needed for recognition at 8px.
; Judge every frame at 1x in design/icons_preview.png before believing it.

; Link session — a ring radiating outward, one frame per beat. The old
; interlocked-rings mark was illegible at 1x (the two rings merged into a
; blob) and said nothing about the session being alive. This says both: the
; word LINK sits beside it in the status row, so the icon is free to carry
; the tempo instead of repeating the name.

; Error / attention. A bold X spanning the whole cell, and deliberately
; static — a steady error is easier to read than a flashing one.
;
; Two earlier attempts failed, and the reason is worth recording so nobody
; retries them. A triangle-with-exclamation needs a container plus interior
; detail, and 8x8 has room for one or the other: drawn as an outline the
; 1 px walls close up and it reads as a seated figure; drawn solid with the
; bang knocked out the tapering silhouette reads as a fir tree.
;
; An X inside a circle — the obvious third idea — cannot work at this size
; either. A circle outline leaves a 4x4 interior, and a 4x4 X has a 2x2
; centre, so the two strokes merge into a square hole: you get a ring with
; a box in it, not a cross. The X needs the full cell for its diagonals to
; be long enough to read as diagonals.
;
; So the container goes and the mark stays. Both states that use this icon
; (no network, no Link session) are failures rather than cautions, and both
; already carry tone "danger", so a cross is the truer symbol anyway.
